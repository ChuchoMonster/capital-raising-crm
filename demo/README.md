# Demo database

A local Postgres database filled with invented data, so the app can be run and
explored without any real contacts, mailboxes or keys.

Every firm, person, email address, deal and figure is generated by the scripts
in this folder from the word lists in `vocab.mjs`. Firm names are built from
coined stems so a combination does not land on a real fund or company, and
every generated email domain ends in `.example`.

## 1. Start a local Postgres on port 5433

Any Postgres 15+ works. With a Homebrew install, for example:

```bash
initdb -D demo/pgdata -U demo --auth=trust
pg_ctl -D demo/pgdata -o "-p 5433 -k /tmp -c listen_addresses=127.0.0.1" \
  -l demo/pg.log start            # later: pg_ctl -D demo/pgdata stop
createdb -h 127.0.0.1 -p 5433 -U demo crm_demo
```

`demo/pgdata` and the log are git-ignored.

## 2. Load the schema

```bash
psql -h 127.0.0.1 -p 5433 -U demo -d crm_demo -c "create extension if not exists pg_trgm"
psql -h 127.0.0.1 -p 5433 -U demo -d crm_demo -f demo/schema.sql
```

## 3. Seed

```bash
export DEMO_PASSWORD=choose-a-local-password
node demo/seed.mjs          # ~12,500 firms and ~31,000 people, deterministic
node demo/seed-deals.mjs    # six raises, outreach history, verdicts, sign-in user
node demo/seed-teaser.mjs   # a two-page teaser on the lead raise
```

The scripts connect to `postgres://demo@127.0.0.1:5433/crm_demo` unless
`DEMO_DB_URL` is set. Re-running `seed.mjs` clears and rewrites the data and
produces the same records every time.

## 4. Run the app

Point `SUPABASE_DB_URL` in `.env.local` at the same database (see
`.env.example`), then `npm run dev` and sign in as `demo@example.com` with the
`DEMO_PASSWORD` you set before seeding.

## Other scripts

| Script | What it does |
|---|---|
| `dump-schema.mjs` | Read-only. Writes the table structure of the database in `SUPABASE_DB_URL` to `schema.sql`. Reads no rows. |
| `shots.mjs` | Signs in and captures screenshots of every page into `demo/shots/` (needs `npm i -D playwright`). |
| `hash.mjs` | The scrypt password hash used for the demo sign-in. |
